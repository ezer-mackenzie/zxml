# Claude Code Instructions

Before making changes, read [AGENTS.md](./AGENTS.md) for project-wide
instructions and [CONTRIBUTING.md](./CONTRIBUTING.md) for contribution
expectations.

- Inspect the relevant source and tests before editing; preserve unrelated
  worktree changes.
- Keep changes scoped to the request and do not claim incomplete XML behavior
  is supported.
- For Zig changes, run the focused tests and formatting check described in
  `AGENTS.md`; report results and remaining limitations.
- Update documentation when behavior or supported features change.
- The project uses the MIT License; do not change the license or add
  source-file license headers unless the maintainer asks.
