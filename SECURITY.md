# Security Policy

## Project status

`zxml` is experimental software and does not yet fully implement or validate
the XML format. Do not rely on it as your sole safeguard when processing
untrusted documents. In particular, the parser still needs work on validation,
entities, comments, and other XML constructs.

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, test documents containing
sensitive data, or exploitation instructions in public issues or discussions.

Send the report privately to the maintainer using the repository's private
vulnerability reporting feature, if enabled. If it is unavailable, contact the
maintainer privately through a channel listed on the repository page or profile.
When possible, include:

- a description of the impact and affected versions or revisions;
- minimal steps to reproduce the issue, avoiding real data or secrets;
- a known mitigation, if one exists.

Please wait for a response before publicly disclosing the issue. No response
time is guaranteed while the project remains in development.

## Scope

This policy covers the code and files maintained in this repository. There are
currently no stable releases or defined security support matrix.
